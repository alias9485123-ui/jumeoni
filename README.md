# 주머니 (Jumeoni)

[Marinara Engine](https://github.com/Pasta-Devs/Marinara-Engine)용 개인 확장(Personal Extension)이에요.
RP 방마다 **지갑 · 상점과 배달 · 가방 · 퀘스트 · 페르소나 비밀 · 메시지(콘보)** 를 따로 두는 단말기 창을 띄우고, 지금 상태를 `{{char}}`에게 숨김 메시지로 알려 줘요.

- 버전: 1.7.3
- 확인한 엔진 버전: Marinara Engine 2.5.2

## 설치

1. 이 저장소의 [`jumeoni.personal-extension.zip`](jumeoni.personal-extension.zip)을 내려받아요.
2. Marinara에서 **Settings → Advanced → Danger Zone** 으로 가서 **Allow third-party extension imports** 를 켜요.
   (서버에 `ENABLE_EXTERNAL_EXTENSIONS=true` 가 필요할 수 있어요.)
3. **Settings → Addons → Personal Extensions** 에서 zip을 가져와요.
4. 가져온 확장은 꺼진 상태예요. **Review and Run** 으로 코드를 확인하고 승인하면 켜져요.
5. 새 버전을 다시 가져오면 같은 이름의 확장이 교체되고, 저장된 데이터는 그대로예요. 다시 승인해야 해요.

`jumeoni/` 폴더에는 같은 내용이 압축 없이 들어 있어요.

## 기능

| 탭 | 하는 일 |
|---|---|
| 지갑 | 내 통장과 NPC 통장, 송금 · 입금 · 출금, 월급, 내역 |
| 상점 | 가게와 품목, 재고. 다 팔리면 AI가 새 물건을 하나 만들어 채워요 |
| 가방 | 산 물건, 사용하기, 2턴에 걸쳐 도착하는 배달 |
| 퀘스트 | 받기 · 완료 · 포기. 답장에 완료 표시가 붙으면 버튼이 알려 줘요 |
| 비밀 | 페르소나 기준 비밀(OFF · 복선 · 공개)을 로어북으로 관리해요 |
| 메시지 | RP 방에 있으면서 캐릭터의 콘보 방과 문자를 주고받아요 |
| 설정 | RP에 전달, 돈 흐름 자동 반영, 콘보 대화 전달, AI 연결, 화면 색(먹색 · 흑백) |

- **세계관 읽기:** 방의 로어북 · 캐릭터 카드 · 페르소나를 읽고 AI가 화폐 · 가게 · 임무 · 잔고 초안을 만들어요. 부르기 전에 예상 토큰을 보여 줘요.
- **자동 반영:** 답장 끝의 `[송금: A → B 금액 | 이유]`, `[입금: …]`, `[출금: …]`, `[임무 완료: 제목]` 표시를 찾아 반영하고, 채팅에서는 그 표시를 지워요. 돈 흐름은 내역에서 되돌릴 수 있어요.
- **콘보 연결:** Marinara의 공식 Connected Chats 링크를 쓰고, 콘보의 최근 문자를 RP에도 참고로 전달해요(공식 링크는 RP가 콘보를 읽지 않아서요).

## 채팅방에서 켜 둘 것

- 채팅방에 모델 연결, 페르소나 지정
- 세계관 읽기를 쓰려면 방에 로어북이 켜져 있어야 해요
- 주머니 설정의 **RP에 전달** 을 켜 두세요
- 메시지 탭을 쓰려면 같은 캐릭터가 있는 콘보 방이 있어야 해요
- 엔진의 명령어(Commands) 기능은 필요 없어요

## 서버 호출

- 주기적으로 서버를 부르지 않아요(폴링 · 새로고침 없음).
- 창을 열 때, 버튼을 누를 때, 답장이 끝났을 때(할 일이 있는 방만), RP 입력을 시작할 때만 필요한 만큼 읽고 써요.
- AI를 부르는 때: 세계관 읽기, 새 퀘스트 받기, 월급 추측하기, 품절 교체, 메시지 보내기.

## 글꼴

Marinara의 보안 설정 때문에 외부 글꼴은 불러오지 않아요. 엔진에 이미 있는 글꼴을 써요.
제목을 명조로, 숫자를 고정폭으로 보고 싶으면 **Settings → Appearance → App → Text & Scale → Google Fonts** 에서
`Nanum Myeongjo`, `IBM Plex Mono` 를 추가하세요. 주머니가 자동으로 그 글꼴을 써요.

## 알아 둘 점

- Marinara의 문서화되지 않은 내부 API를 쓰는 부분이 있어요. 엔진이 업데이트되면 동작이 바뀔 수 있어요.
- 답장 끝 신호(`marinara:generation-complete`)가 가끔 오지 않아요. 놓친 답장은 다음에 창을 열거나 입력을 시작할 때 반영해요.
- 숨김 메시지와 표시는 모델에게 주는 참고 정보라, 모델에 따라 반영 정도가 달라요.
